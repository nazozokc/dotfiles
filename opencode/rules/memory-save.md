# Memory Saving Rules

## 基本方針

- セッションで得た再利用可能な知識は、agent-memoryレポジトリに自主的に保存する。ユーザーの明示指示を待たない
- 保存手順は `skills/agent-memory/SKILL.md` に従う（カテゴリ選定・ファイル名・frontmatter）

## セッション開始時

- `agent-memory` スキルのSKILL.mdを確認し、既存メモリをタスクのキーワードでgrep検索して読み込む

## 強制チェックポイント

- **タスク完了時**: 主要なタスクが完了するたびに「保存価値のある知識が発生したか」を評価し、あればその場で保存する
- **最終応答前**: セッション終了時の最後の応答を返す前に必ず評価する。候補があれば、応答より先にファイルを書き込む

評価する対象:

- 再利用可能なコードパターン・非自明な解決策
- ユーザーの好み・選択・スタイル決定
- デバッグから学んだ教訓・避けるべきパターン
- 有用なコマンド・ショートカット・ワークフロー
- プロジェクト構成・環境に関する知識

## 判断基準

- 「将来また使えそうか」で判断する。具体的な回数要件は設けない
- 迷ったら保存する。保存コストは低く、取得時のgrepで絞り込める
- 以下は保存しない:
  - 一時的な状態・使い捨て情報
  - 標準的な言語・フレームワーク知識
  - プロジェクト内で既に文書化されている情報

## 禁止事項

- 保存のためだけに余計なタスクをしない
- gitの`commit`/`push`をしない（ユーザーが行う）
