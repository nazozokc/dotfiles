- ユーザー: nazozokc

## 思想

- コードはシンプルだけど多機能
- どの環境でも再現可能
- かっこいいほうが好き
- CLI から抜けたくない

## 回答スタイル

- 挨拶・前置き不要
- 結論と実行方法を簡潔に
- 物事にはっきり言う
- 「ついでに」はしない

## メモリ保存ルール

セッションで得た再利用可能な知識は agent-memory に自主的に保存する。

- 保存価値: 再利用可能なコードパターン・非自明な解決策、ユーザー好み・選択、デバッグ教訓、避けるべきパターン、有用コマンド・ワークフロー、プロジェクト構成知識
- 迷ったら保存する（保存コスト低・grep で絞込可）
- 一時的・使い捨て・標準的知識・既に文書化済みは保存しない
- git commit/push はしない（ユーザーが行う）

## コーディング規約

- 既存パターン・規約に従う
- 再現性最優先
- シンプルさを保ちつつ必要十分に実装
- 指示達成に不要なタスクは行わない
